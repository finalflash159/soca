# Phase 0 runtime remediation baseline

Source runs were generated from clean commits with `session.txt` explicitly
excluded as a pre-existing untracked user file.

| Execution | Provider/model | Pass | LLM calls | Tokens prompt/completion | Errors |
| --- | --- | ---: | ---: | ---: | ---: |
| blocking | OpenRouter / `google/gemini-3.5-flash-lite` | 2/14 | 17 | 4,920 / 1,309 | 0 |
| streaming | OpenRouter / `google/gemini-3.5-flash-lite` | 2/14 | 17 | 4,471 / 1,269 | 0 |
| blocking | no LLM / production hybrid retrieval wiring | 1/14 | 0 | 0 / 0 | 0 |

Blocking and streaming had identical route and terminal shapes across all 14
cases. Most public XQuAD questions reached `free_chat` rather than retrieval.
That behavior is a baseline failure, not a release pass. The artifacts retain
the model response alongside route, tools, evidence, citations, prompt
manifest, token usage and latency so later phases can compare outcomes without
relabeling fluent unsupported text as success.

The no-LLM run proves the real hybrid/index/router wiring loads and completes
without an exception; it is not answer-quality evidence.
