# Hồ sơ người dùng

## Ngôn ngữ và phong cách

- Ưu tiên được giải thích bằng tiếng Việt; khi cần thuật ngữ kỹ thuật thì kèm English.
- Thích câu trả lời ngắn gọn, đi thẳng trọng tâm, giọng thân thiện.
- Ví dụ code ưu tiên ngôn ngữ Python.
- Ghi chú lưu ở định dạng Markdown.

## Thói quen làm việc

- Luôn kiểm thử bằng pytest trước khi tạo pull request.
- Mỗi thay đổi nằm trên một branch riêng, kèm review kỹ trước khi hợp nhất.
- Thích câu trả lời có citation nguồn real thay vì phỏng đoán.
- Tri thức lưu trong ByteRover; memory dạng unscoped là mặc định khi chưa gắn scope.
