# SoCa knowledge demo vault

This is the canonical assistant-like demo fixture. It contains two
explicit slices: `learning_notes` and `life_vault`.

The project notes are derived from checked-in SoCa documentation. The
finance note is explicitly synthetic demo data; it is not personal
financial information. The health note is a safety boundary, not
medical advice. Rebuild with `uv run python scripts/seed_demo_knowledge.py
--fixture`.
